AI-FSR is an AI-powered Food Safety & Regulatory Compliance Platform designed for the food industry. It automates audits, tracks incidents, manages CAPA (Corrective and Preventive Actions), and ensures compliance with FSSAI, HACCP, and ISO 22000 regulations.

07 Authentication Flow

■ Signup Flow

1
User submits signup form
Name, email, password, organization name
2
Backend creates organization
INSERT INTO organizations with FSSAI pending status
3
Backend creates user
Password hashed with bcrypt (10 rounds), role = admin
4
JWT token returned
Token includes userId, email, role. Stored in localStorage.

■ Login Flow

1
User enters credentials
Email + password
2
Backend validates
bcrypt compare, check active status
3
JWT token + user object returned
All subsequent requests include Authorization: Bearer token

■ Password Reset Flow

1
User enters email
POST /api/auth/forgot-password → generates 6-digit OTP
2
OTP verification
POST /api/auth/verify-reset-otp → returns reset_token (JWT, 15min)
3
Password reset
POST /api/auth/reset-password with new password + reset_token

10 Organization Isolation

All data is isolated by organization. Users only see data belonging to their organization.

■ Implementation

1
User has organization_id FK
Linked to organizations table via foreign key
2
Backend resolves org on login
JWT token contains userId, org resolved from DB
3
All queries filter by org
WHERE organization_id = ANY(orgIds)

■ Multi-Plant Query Pattern

-- Find all org IDs with same name (all plants) SELECT id FROM organizations WHERE name = $1 -- Query across all plants of same org SELECT * FROM checklist WHERE organization_id = ANY($1)

11 Database Adapter

Dual-Mode Support

The database.js module supports both PostgreSQL and SQLite transparently. No code changes needed between environments.

// database.js logic const USE_PG = !!process.env.DATABASE_URL; if (USE_PG) { // PostgreSQL mode (production) // Uses pg Pool, native SQL syntax } else { // SQLite mode (local development) // Converts PostgreSQL syntax: // $1, $2 → ? placeholders // RETURNING → INSERT + SELECT // NOW() → CURRENT_TIMESTAMP // FILTER (WHERE ...) → SUM(CASE WHEN ...) // ANY($1) → IN (?, ?, ...) // ::int → CAST(... AS INTEGER) }
